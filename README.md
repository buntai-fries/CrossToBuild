# CrossToBuild

> A game developed by **buntai-fries** for [Regenerate Game Jam 2026](https://itch.io/jam/regenerate-game-jam-2026)

---

## About

**CrossToBuild** is a Unity 2D game created as part of the Regenerate Game Jam 2026. This repository tracks all assets, code, and project files produced during the jam.

The project is built on top of the [gamejam-starter-kit-urp](https://github.com/Barnaff/gamejam-starter-kit-urp) template, using Unity's Universal Render Pipeline (URP) for 2D rendering.

---

## Built With

- **Unity** — Game engine (2D with URP)
- **C#** — Game logic and scripting
- **Universal Render Pipeline (URP)** — Rendering pipeline

## Getting Started

### Prerequisites:

- **Unity Hub** — [Download here](https://unity.com/download)
- A compatible version of the **Unity Editor** (check `ProjectSettings/ProjectVersion.txt` for the exact version - 6.3 LTS)

### Opening the Project:

1. Clone the repository:
   ```bash
   git clone https://github.com/buntai-fries/CrossToBuild.git
   ```

2. Open **Unity Hub**, click **Open**, and navigate to the cloned folder.

3. Unity will import all packages and assets automatically on first open. This may take a few minutes.

4. Once loaded, open the main scene from the `Assets/` folder and hit **Play** to run the game.
